Source continuity
The 10 original source files matched the authoring draft byte-for-byte.
Package.swift, both core source files and the 14 core tests were unchanged.
UI sample additions wait for the typed value, reject a stale save badge,
and guard against a placeholder being mistaken for entered text.
A standalone synthetic UIKit/UIScene host and four safety tests were added.
No private application code, real user records or production accounts were used.

Limitations
Only the synthetic card's selected question field was verified after restart.
This does not validate a real application or its whole database, Core Data,
SwiftData, sync, migrations, crash recovery, OS kills or disk-full handling.
Physical devices and older macOS/iOS versions have NOT been tested.
iOS 15 is a declared library/host minimum; UI tests declare iOS 17. Neither older runtime was exercised.
The UI sample had two animation-related waits of about 60 seconds;
all final tests passed, but UI-test timing was not consistently fast.
An initial host run failed due to missing UIScene lifecycle support;
the host was fixed and the final five tests were rerun successfully.

Packaging
This distribution contains source, synthetic host tests and documentation only.
Machine paths, simulator identifiers, raw logs and xcresult bundles are excluded.
The validation evidence archive is retained separately for private review.
